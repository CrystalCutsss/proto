# proto

Среда прототипирования «Figma → код → защищённый хостинг»:
- интерактивные веб-прототипы собираются из макетов на токенах дизайн-системы;
- у каждого прототипа есть версии;
- прототипы публикуются по ссылке под логином и паролем.

> Среда строится по фазам. Текущее состояние — в [`docs/STATUS.md`](docs/STATUS.md).

## Как продолжить работу (только браузер)

1. Откройте https://claude.ai/code и выберите репозиторий `CrystalCutsss/proto` и окружение `proto` ([настройка окружения](docs/setup/environment-audit.md#7-что-сделать-в-браузере)).
2. Напишите: **«Прочитай docs/STATUS.md и продолжи»**.
3. Каждая фаза заканчивается PR. После ревью смержите его на GitHub и напишите в сессии «go».

## Документы

- [`docs/STATUS.md`](docs/STATUS.md) — текущая фаза, следующий шаг, ожидаемые действия.
- [`docs/setup/environment-audit.md`](docs/setup/environment-audit.md) — аудит облачной сессии, setup-скрипт, сеть.
