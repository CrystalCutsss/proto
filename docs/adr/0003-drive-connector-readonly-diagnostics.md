# 0003. Коннектор Google Drive — только для диагностики, только чтение

- Статус: Принято
- Дата: 2026-10-13
- Фаза: 0

## Контекст
- По архитектуре облачная сессия не хранит секретов и не ходит в Drive. Данные из Drive приходят в репозиторий только через GitHub Actions и PR (Фаза 2).
- Владелец сообщил, что доступ к папке Proto — «Редактор», и попросил это проверить. Из сессии проверить нельзя: `drive.google.com` закрыт сетью, а Drive API без учётных данных отвечает 403 «unregistered callers» (см. [аудит, раздел 5](../setup/environment-audit.md#5-доступ-к-google-drive)).
- В каталоге коннекторов claude.ai есть **Google Drive** с инструментами `get_file_metadata` и `get_file_permissions`. Его трафик идёт через серверы Anthropic: учётные данные в VM не попадают, правки allowlist не нужны.

## Варианты
1. **Ждать первого прогона `drive-inventory` (Фаза 2a).** Он показывает права сервисного аккаунта, но не настройки общего доступа и не роль владельца. К тому же проверка откладывается до настройки GCP.
2. **Временно открыть `drive.google.com` в allowlist.** Видно только, открыта ли папка по ссылке, роли не видны. К тому же это нарушает правило «сессия в Drive не ходит».
3. **Коннектор Google Drive только для чтения.** Видны метаданные, права, владелец, тип диска и ярлыки. Проверка возможна сразу.

## Решение
Вариант 3 (выбор владельца):
- Коннектор используется **только для диагностики**: метаданные и права папок Proto и DS, проверка структуры.
- Инструменты записи коннектора владелец отключает в настройках коннектора.
- В Фазе 4 PreToolUse-хук дополнительно запрещает вызовы инструментов записи Drive (`create`, `copy`, `upload`, `update`, `delete`, `move`, `rename`), даже если их включат.
- **Конвейер данных не меняется.** Inventory, синхронизация DS и Inbox идут только через GitHub Actions, и файлы ДС в репозиторий приходят только PR от `ds-sync`.
- Результаты проверки записываются в `docs/setup/environment-audit.md`. Email участников маскируется.

## Последствия
- Это исключение из правила «сессия не ходит в Drive», ограниченное чтением метаданных. Его нужно помнить при ревью skills: ни один skill не должен использовать коннектор для чтения или копирования содержимого ДС.
- Коннектор подхватывается при старте сессии. Если в текущей сессии его нет, проверка переносится в следующую (через `docs/STATUS.md`).
- Пересмотреть, если коннектор станет не нужен: после стабильной работы `ds-check` в Actions его можно отключить.
